# Hotel Booking Automated Testing Suite

Лабораторна робота №6 з дисципліни «Професійний Python»

## Опис проєкту

Проєкт демонструє побудову повноцінного комплексу автоматизованого тестування (Automated Test Suite) для системи бронювання готелю (Варіант 8) з використанням фреймворку `pytest`.
У межах роботи реалізовано:
- **Unit та Integration тести** для перевірки ізольованої та спільної роботи компонентів.
- **Fixtures та Parametrization** для уникнення дублювання коду та ефективного тестування різних наборів даних.
- **Mocks, AsyncMock та side_effects** для ізоляції зовнішніх залежностей (платіжних шлюзів, сервісів нотифікацій).
- Ізольовану перевірку взаємодії з файловою системою через фікстуру `tmp_path`.
- Підміну конфігурації (Environment variables) під час виконання тестів за допомогою `monkeypatch`.
- Аналіз Statement та Branch покриття коду за допомогою `pytest-cov`.

## Вимоги

- Python 3.10+
- uv (для швидкого керування залежностями)
- pytest, pytest-cov, pytest-asyncio

## Встановлення та запуск

1. Встановлення залежностей через `uv`:

```bash
uv sync
```

2. Запуск усього комплексу тестів із генерацією звіту про покриття (coverage report):

```bash
uv run pytest -v --cov=src/hotel --cov-branch --cov-report=term-missing
```

3. Запуск виключно інтеграційних тестів (використання маркерів):

```bash
uv run pytest -m integration -v
```
